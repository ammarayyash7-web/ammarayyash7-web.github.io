Installation & privacy details
Android · Install on your phone
  1. Open this website on your Android phone and choose the Android download for your app.
  2. Open the downloaded APK. Android may ask you to allow this browser to install apps; enable this only if you trust this download.
  3. Tap Install, then Open. Complete the app’s first-launch setup.

Already using the app? Update from Settings → App updates inside that app. Keep it installed to preserve its records. The main Android buttons are for new website installations. Earlier original installations use a separate matching installer for the first update; choosing the standard website APK would install a second app with separate records.

Already have an earlier Android installation?

Keep the app holding your records installed. If it was installed directly during development, use its matching original-installation update below. It updates that existing app; no data transfer or uninstall is needed. After this first update, use Settings → App updates inside the app. If Android says it cannot update, stop and keep your existing app installed.

Monthly backups & manual export

Both apps offer optional automatic monthly backups on Android and Windows. Turn them on in Settings, choose a backup password and keep that password somewhere safe. A backup is saved immediately, then once each calendar month when you next use the app. The apps do not need to be paired.

On Android 10 or later, use Files → Downloads → WealthManager or MyRoutineHub → Backups. On Windows, the default is Documents → WealthManager or MyRoutineHub → Backups; you can choose another folder. Android 9 and earlier use app storage, so keep manual exports elsewhere before uninstalling.

Back up now and the existing Export options remain available. Monthly files are password-protected and stay on your device. Use Import / Restore backup and enter the backup password to recover them. Keep an extra copy on another device or drive; a backup on a lost device cannot help you recover it.

Passwords, device security settings and Routine Hub’s password vault are excluded. Routine Hub’s phone system-calendar events are also excluded. Previously exported files are kept until you delete them yourself. Ordinary Excel, CSV and plain JSON exports are not password-protected.

Windows · Install Wealth Manager
  1. Download the Windows ZIP and choose Extract All.
  2. Keep the extracted folder together. Open WealthManagerWindows, then run wealth_manager.exe.
  3. Complete setup. You can create a desktop shortcut to the executable.

For Windows PCs with an Intel or AMD 64-bit processor. This portable build is not Microsoft Store certified or commercially code-signed. Windows may display an unfamiliar-publisher notice. If Windows blocks it, stop and verify the source before proceeding.

Windows · Install My Routine Hub & transfer data
  1. Download the Windows ZIP, choose Extract All and keep the complete MyRoutineHubWindows folder together.
  2. Run my_routine_hub.exe. You can create a desktop shortcut. For Windows 10/11 Intel/AMD x64; not a Microsoft Store or commercially code-signed installer.
  3. Settings → App updates checks for new releases. Choose Update inside the app to download, verify and restart the same installation; your saved records stay on this PC. For this first manual Windows update, extract the complete new ZIP and open its executable.
  4. For wireless sync, open Settings → Local Wi-Fi sync on both devices. On Windows show the pairing QR code; scan it on Android and approve the matching six-digit number on the computer. The connection is remembered. Both apps must stay open on the same private network. Latest saved additions, edits and deletions sync automatically. Both apps keep local safety copies before automatic replacements. Update both paired devices to the latest version. Guest-network isolation or a firewall may prevent connections. Backup-file transfer remains available; backup imports replace data rather than merge it.

Backups are not encrypted. Password vault and phone system-calendar events are excluded; local Windows calendar events are included. Windows does not provide scheduled background routine reminders. Update checks fetch only a public version file; you can disable them in Settings.

Your data & permissions

Downloads contain the apps, not anyone’s personal records. Your entries are stored locally. The website does not receive your financial records or routines. Local storage does not guarantee immunity from device theft, malware or unauthorised access. Protect your device and backups.

Wealth Manager can read receipt photos and screenshots locally in English, Norwegian and Arabic. Choose an image or use the camera, review the extracted details, then save the transaction. No receipt image copy is saved by the app or uploaded; your gallery original stays in Photos. Wealth Manager can request market prices and currency rates from external providers. Optional broker reporting uses the credentials you configure. USB sync remains available. Optional local Wi-Fi sync encrypts transfers between your explicitly paired devices; other people sharing the Wi-Fi are not paired automatically. Exports and backups go where you choose to save or share them.

My Routine Hub stores routines, notes and any cycle-tracking entries on the device. Optional Wi-Fi sync shares selected app data, including notes and cycle history, with your approved computer. The password vault, phone system calendars, reminder permissions and device appearance stay local. Camera access scans pairing codes locally. Calendar access and notification permissions support the optional features you enable. Review these permissions in Android settings. Keep backups private and delete entries through the app when no longer needed.

GitHub hosts the downloads and processes download traffic under its own privacy policy.

Both apps show update notices and let you check in Settings → App updates. Tap Update to download a verified installer for that same app. Android asks for installation approval; Windows restarts to complete the update. Keep your app installed and your saved records stay in its existing storage.
